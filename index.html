Self-Improving Cycle

The compounding memory loop

How Ultra ensures that every task completed makes tomorrow's work faster. A closed-loop protocol from context injection to durable knowledge promotion.

3lm start → Execute → 3lm end → 3lm learn → 3lm promote → vault-index
  • Episodic capture: 3lm end files what happened in the session, establishing an immutable audit trail of decisions and outcomes.
  • Scored lessons: 3lm learn extracts tactical observations and assigns confidence scores to each takeaway.
  • Promoted knowledge: 3lm promote --min 70 graduates tested lessons into semantic principles and procedural runbooks.
  • Self-documenting indexing: vault-index and knowledge-graph re-index all nodes so that future sessions inject proven guidelines automatically.
