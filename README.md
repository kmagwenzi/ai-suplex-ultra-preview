# AI-Suplex Ultra — product preview

The public preview page for **AI-Suplex Ultra**, the paid harness on top of the free **AI-Suplex 777** library.

- **What it is:** a static HTML/CSS page (`index.html` + `assets/`). No framework, no build step.
- **Publish directory:** the repo root (`netlify.toml` sets `publish = "."` and `command = ""`).
- **Deploy:** Netlify, auto-deploying on every push to `main`.
- **Live:** https://ai-suplex-ultra-preview.netlify.app/

## Company site

This is the preview surface. It is planned to move to https://ai-suplex.co.zw/projects/ai-suplex-ultra.html. Until then, its `canonical` and `og:url` point at the Netlify preview URL.
